# Definition of Ready (DoR)

Una historia está **lista** para entrar a un sprint si cumple:

- [x] Tiene código (HU-XX) y prioridad MoSCoW
- [x] Tiene rol (Como…), funcionalidad (Quiero…) y beneficio (Para…)
- [x] Tiene al menos 1 criterio de aceptación en formato Given-When-Then
- [x] Está estimada en story points por el equipo (Planning Poker)
- [x] No tiene dependencias bloqueantes sin resolver
- [x] Está vinculada a un requisito (RF-INV-XX)
- [x] Es entregable dentro de un sprint (≤ 8 puntos)
