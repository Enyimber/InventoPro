# Definition of Done (DoD)

Una historia está **terminada** cuando:

- [x] Código compilado sin errores ni warnings
- [x] Pruebas unitarias escritas (cobertura ≥ 75% por clase modificada)
- [x] Pull Request revisado y aprobado por al menos 1 par
- [x] Mergeado a `main` y pipeline CI/CD verde (build + tests + Sonar)
- [x] Documentación Swagger actualizada (si hay endpoints REST)
- [x] Probado manualmente contra los criterios de aceptación
- [x] Desplegado en ambiente de QA en Railway
- [x] Aprobado por el Product Owner en Sprint Review
